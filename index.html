Arabic Transliterator

Convert romanized text to Arabic script

Input (Latin)
Output (Arabic)

Quick Reference

This tool supports both standard transliteration and Franco-Arabic (Arabizi) where numbers represent Arabic letters:

kh→خ
sh→ش
gh→غ
3→ع (ayn)
7→ح (ha)
9→ق (qaf)

Examples

  • marhabanمارحابان
  • shukranشوكران
  • as-salamu 3alaykumاس-سالامو عالایكوم
  • kayfa 7alakكایفا حالاك
  • ahlan wa sahlanاحلان وا ساحلان
