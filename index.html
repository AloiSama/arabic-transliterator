🌙 Arabic Transliterator

Convert Latin text to Arabic script automatically

How to use:

Type romanized Arabic text in the left box. Supports both formal transliteration (e.g., kh, sh) and Franco-Arabic/Arabizi numbers (e.g., 3 for ع, 7 for ح, 9 for ق).

Try these examples:

marhaban → مرحبا
as-salamu 3alaykum → اس-سلامو علیكوم
shukran → شكران
kayfa 7alak → كیفا حالاك
ahlan wa sahlan → احلان وا ساحلان
